# The World Today — 18 November 2026

One image summing up the world news of Wednesday 18 November 2026,
drawn entirely by code (flat vector-style icons and real text, no photos).

The broadsheet grid covers eight stories from the day: Iran's strikes on
Kuwait and Bahrain, Ukraine's attack on the Kerch Bridge, Xi meeting Putin
in Shenzhen, Democrats taking the U.S. Senate, Israel electing a new
Knesset speaker, Ebola passing 11,000 cases in DR Congo, Nvidia's record
$115.8B quarter, and winter cold in Gaza's tents. The masthead names the
day in large type, and every panel pairs a small icon with a short headline
and a one-line subhead, so the day reads at a glance — even at thumbnail
size, where the date and the lead story stay legible.

## How to run

```sh
python3 main.py
```

This copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`) as
`entry.png`. Standard library only, no network, and both runs write
identical bytes.
